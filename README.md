# Uzb-AI-kulguli-videolar — Website

This repository contains a small static website (HTML/CSS/JS) designed to be deployed on Vercel.

How to deploy

1. Push this repo to GitHub (already done).
2. Import the repository into Vercel (https://vercel.com/new) — Vercel will detect a static site.
3. No build step required; the root `index.html` will be served.

Files
- index.html — main page
- styles.css — styling
- script.js — lightweight interactions

Customize
Replace the video thumbnails and links with real content. Hook up the contact form to your backend or a service like Formspree, Netlify Forms, or Vercel Functions.
